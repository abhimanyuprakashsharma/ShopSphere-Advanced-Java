## Slide 2 — Problem Statement
A web-based shopping application needs product discovery, customer accounts, cart and order workflows, and administration in one system. ShopSphere demonstrates these workflows as an academic Advanced Java project.

## Slide 3 — Objectives
- Demonstrate Java web application architecture and persistence with JDBC/MySQL.
- Implement customer shopping and administrative workflows.
- Demonstrate syllabus concepts including Swing MVC, sockets, RMI, servlets, JSP, serialization, JNDI and internationalization.

## Slide 4 — Technology Stack
- Java 17
- Jakarta Servlet / JSP / JSTL
- JDBC and MySQL
- Maven and Apache Tomcat 11
- HTML, CSS and JavaScript

## Slide 5 — Architecture
Browser (HTML/JSP/JavaScript) → Servlet controllers → service layer → DAO/JDBC → MySQL. Cross-cutting filters support concerns such as CSRF checks, request handling and security headers.

## Slide 6 — Customer Features
Registration and login, product listing/search/filter/sort, cart, wishlist, address management, coupons, checkout, order history, profile and reviews.

## Slide 7 — Admin Features
Product/category management, inventory, customer/order/review management, coupons, analytics and CSV export.

## Slide 8 — Security and Data Handling
The codebase includes prepared SQL statements, password hashing, input validation, CSRF protections, security headers, session hardening and authorization checks. Explain and demonstrate only features that have been verified in the running build.

## Slide 9 — Advanced Java Lab Demonstrations
Swing student registration, MVC calculator, JDBC database access, socket client/server, Java RMI, servlet form handling, and servlet filters/listeners/session examples.

## Slide 10 — Testing and Deployment
The repository includes JUnit tests and a Maven CI workflow. The documented deployment target is Tomcat 11 with a configured MySQL datasource. Run the project and tests before presenting; do not describe a feature as tested unless you verified it.

## Slide 11 — Limitations and Future Scope
Payment recording is mock/local rather than a live payment gateway. Future improvements could include a real payment provider, persistent rate limiting, production email delivery and richer monitoring.

## Slide 12 — Conclusion and Q&A
ShopSphere brings together e-commerce workflows and Advanced Java demonstrations in one educational codebase. Be ready to explain the architecture, database flow, security checks, and the changes personally made for this submission.
