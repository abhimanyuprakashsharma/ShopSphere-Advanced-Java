# Advanced Java Lab

This folder contains the Java lab work and advanced Java practice modules for the RTU Advanced Java syllabus.

## Included modules
- LAB_No.1 to LAB_No.7
- Swing-based GUI experiments
- JDBC demos
- Socket programming
- Java RMI experiments
- Servlet lab exercises
- JNDI / I18n / network examples

## Project separation
- `shopsphere/` = main e-commerce project
- `advanced-java-lab/` = practice, experiments, and advanced Java concept demos
